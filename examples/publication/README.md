# Publication gallery

Inputs and recipes for a small, reproducible set of figures made with Ycrystal and
POV-Ray 3.7 (FR-GALLERY-01). They serve three purposes: candidate figures for a paper,
a sample gallery for new users, and a reproducibility supplement. Every image is
rendered by the production command line from the files listed here. The rendered
images themselves are not stored in Git; one command makes them again.

Thumbnails and the figure-methods table of a recorded run are in the
[gallery guide](../../docs/guide/gallery.md). A proposal for arranging them as journal
figures is in [manuscript figures](../../docs/development/manuscript-figures.md).

## What it shows

| Figure | Case | How it is made |
| --- | --- | --- |
| `srtio3.png` | (a) Perovskite SrTiO3 in a restrained style for a journal page | Batch job, `styles/paper.ycstyle`, default view at a fixed visible height of 9 Å |
| `srtio3-cover-light.png` | Same geometry and camera, cover environment only | `srtio3.ycrystal` snapshot + `styles/cover.ycstyle`, part `environment` |
| `srtio3-cover.png` | Same geometry and camera, cover environment and materials | Same snapshot, parts `appearance,environment` |
| `bazro3-mapped.png` | (b) A chemically different perovskite with the transferred style | Batch job, explicit element mapping Sr → Ba, Ti → Zr, same 9 Å scale |
| `mgb2.png` | (b) A hexagonal crystal with the same style | Batch job on `../MgB2-gradient.ycrystal` (3 × 3 × 1 cells), looking down c; Mg and B keep their default colours |
| `kyanite.png` | (c) A low-symmetry (triclinic, P-1) mineral with its bonds and cell | Batch job, default view |
| `afm-synthetic.png` | (d) A **synthetic** magnetic-moment illustration, not a real material | Batch job on `../vectors-synthetic-afm.ycrystal`, looking down a |

The element mapping and the materials are presentation choices. They do not state
chemical equivalence, site correspondence, or physical properties: chrome Ti does not
mean metallic Ti.

## Files

| File | Contents |
| --- | --- |
| `gallery.json` | Batch manifest (schema 1) of the five batch figures, with `"save_projects": true` |
| `styles/paper.ycstyle` | Restrained style: satin, white background, soft lighting, colour-blind-safe Okabe–Ito colours for the perovskite sites (Sr bluish green, Ti blue, O vermillion), 1600 × 1200 px |
| `styles/cover.ycstyle` | The same colours with ceramic Sr, chrome Ti, ruby-glass O, in a dark studio with a reflective floor and a point key light (hard shadows); no radius changes, so it keeps a snapshot's geometry |
| `structures/SrTiO3.cif` | SrTiO3, Pm-3m, a = 3.905 Å (copy of `tests/fixtures/SrTiO3.cif`) |
| `structures/BaZrO3.cif` | BaZrO3, Pm-3m, a = 4.19 Å, rounded, for demonstration (copy of `tests/fixtures/BaZrO3.cif`) |
| `structures/kyanite-COD-1008755.cif` | Kyanite, Al₂SiO₅, P-1, 32 atoms per cell, from the Crystallography Open Database (see below) |

The styles are generated by `python scripts/make_examples.py`, which writes them from
code with fixed timestamps; `tests/test_gallery.py` checks that the tracked files are
exactly what it writes. Two inputs are the example projects one folder up:
- `../MgB2-gradient.ycrystal`, made from `tests/fixtures/MgB2.cif`;
- `../vectors-synthetic-afm.ycrystal`.

## Make the figures

```bash
python scripts/make_gallery.py --out artifacts/gallery                  # 1600 × 1200
python scripts/make_gallery.py --out artifacts/gallery-small --scale 0.25  # quick check
```

`artifacts/` is ignored by Git. The script uses only the production command line, in
these steps:

1. **Batch series.** It copies the inputs to a temporary folder and runs
   `ycrystal --batch gallery.json` there. Every figure gets a snapshot and a provenance
   record.
2. **Controlled variants.** It renders the two SrTiO3 variants from the
   `srtio3.ycrystal` snapshot with `--style styles/cover.ycstyle`.
3. **Replay without sources.** It deletes the temporary inputs, then renders every
   snapshot again with `scripts/replay_check.py` and compares the pixels.
4. **Records.** It writes:
   - `figure-methods.md` and `figure-methods.json`, from the provenance records:
     input, atoms, size, style, mapping, camera, key settings, renderer;
   - `commands.txt`, the commands it ran.

`--thumbnails DIR` also writes the small JPEG copies used in the documentation.

## Provenance and licences

- **SrTiO3, BaZrO3, MgB2.** Small input files written by hand for this project from
  textbook lattice constants (MIT, like the repository). They describe real compounds
  with rounded constants and are not refined reference data
  (`tests/fixtures/README.md`).
- **Kyanite.** Entry 1008755 of the
  [Crystallography Open Database](https://www.crystallography.net/cod/1008755.html),
  downloaded on 17 November 2026 and kept unchanged. SHA-256:
  `0d776c5e5c0fff0a45eb763a9dcaa4ab51af2e0d81937fddaa863eea810e36c3`. The COD dedicates
  its data to the public domain (CC0) and asks users to credit the original authors:
  C. de Rango, G. Tsoucaris, C. Zelwer, J. Devaux, "Comparaison de deux affinements de
  la structure de la cyanite", *Bull. Soc. fr. Minéral. Cristallogr.* **89**, 419–424
  (1966). The file is fully ordered (all occupancies 1).
- **Synthetic antiferromagnet.** Two Fe sites in a cubic cell (a = 2.87 Å) with moments
  of +2.2 and −2.2 μB assigned by hand along z. It illustrates atom-attached vectors and
  is **not a real material** or a claim about any magnetic ground state.
- **Rendering.** POV-Ray 3.7 and its standard include files (`textures.inc` for chrome
  and ruby glass) belong to the POV-Ray installation (AGPL-3.0) and are not part of
  these files. No background pictures or other third-party images are used.
