Material, environment, and lighting presets¶

presets ¶

Material, environment, and lighting presets.

Every preset is a small JSON manifest shipped with the package: one file per material in presets/materials/, one per environment in presets/environments/, and the lighting presets in presets/lighting.json. Each material and environment also has a thumbnail rendered by POV-Ray (presets/thumbnails/, regenerated with scripts/render_thumbnails.py).

A material records how POV-Ray draws it (one of four declaration kinds, see Material), the native POV-Ray identifiers it uses, the standard include files they need, whether it keeps the element colour, and an approximation for the live VTK view. An environment preset initialises the background, the floor, and the lighting of an Environment; the user can change each of them afterwards.

Examples:

>>> from ycrystal.presets import DEFAULT_MATERIAL, get_material, materials
>>> DEFAULT_MATERIAL
'satin'
>>> len(materials()) >= 20
True
>>> gold = get_material("gold")
>>> gold.kind, gold.native, gold.includes, gold.keeps_element_color
('texture', ('T_Gold_3C',), ('metals.inc',), False)
>>> [m.id for m in materials() if m.matches("marble")]
['marble']

LiveLook dataclass ¶

LiveLook(ambient: float = 0.1, diffuse: float = 0.8, specular: float = 0.3, specular_power: float = 40.0, opacity: float = 1.0, color: RGB | None = None)

Approximate surface properties for the live VTK view (Phong shading).

Attributes:

    Lighting coefficients between 0 and 1.

Material dataclass ¶

Material(id: str, name: str, description: str, category: str, kind: str, finish: str = '', pigment: str = '', texture: str = '', material: str = '', normal: str = '', filter: float = 0.0, interior: str = '', keeps_element_color: bool = True, native: tuple[str, ...] = (), includes: tuple[str, ...] = (), texture_space: str = 'world', texture_scale: float = 1.0, live: LiveLook = LiveLook(), min_povray: str = '3.7', provenance: str = '', order: int = 0, base: str = '', parameters: tuple[tuple[str, float], ...] = ())

A material preset.

Attributes:

  • id (str) –

    Stable identifier stored in projects (e.g. "satin").

  • name, description –

    Text shown in the interface.

  • category (str) –

    One of MATERIAL_CATEGORIES.

  • kind (str) –

    Declaration kind:

    "finish" The element colour as pigment with the finish (and optional normal). "pigment" A native or written pigment (own colours) with the finish. "texture" A complete native texture (own colours), for example T_Gold_3C. "material" A material with an interior: either the native identifier in material (own colours) or, without it, the element colour with filter, finish, optional normal, and interior.

  • finish (str) –

    Contents of the finish { … } block: a recipe or a native identifier.

  • pigment (str) –

    Contents of the pigment { … } block of a "pigment" material.

  • texture (str) –

    Contents of the texture { … } block of a "texture" material.

  • material (str) –

    Native material identifier of a "material" kind, or empty for a recipe.

  • normal (str) –

    Contents of an optional normal { … } block (surface relief).

  • filter (float) –

    Pigment filter amount (0 opaque … 1 fully transparent) of a material recipe.

  • interior (str) –

    Contents of the interior { … } block of a material recipe, or empty.

  • keeps_element_color (bool) –

    Whether the element colour remains visible. False for materials with their own pigment; the gallery says so instead of silently replacing colours.

  • native (tuple[str, ...]) –

    Native POV-Ray identifiers the material uses (shown and searchable).

  • includes (tuple[str, ...]) –

    Standard POV-Ray include files that declare them, in loading order.

  • texture_space (str) –

    "unit": the texture is applied to a unit sphere that is then scaled to the atom radius and moved to the atom, so procedural patterns have the same size on every atom. "world": applied in world coordinates (Å).

  • texture_scale (float) –

    Extra uniform scale of the texture or pigment in its texture space.

  • live (LiveLook) –

    Approximation for the live view.

  • min_povray, provenance –

    Required POV-Ray version and origin of the recipe or identifiers.

  • order (int) –

    Position in the catalog.

  • base (str) –

    For a custom variant: the built-in material it was made from; empty otherwise.

  • parameters (tuple[tuple[str, float], ...]) –

    For a custom variant: its parameter values (see ycrystal.presets.custom).

Custom material variants¶

custom ¶

Custom material variants made from Ycrystal's own recipes (FR-MATERIAL-01).

A variant starts from a built-in material whose recipe Ycrystal writes itself and changes some of its parameters. The parameters are typed numbers with explicit ranges (see SCHEMAS); the POV-Ray 3.7 recipe text is generated from them, never edited as text. Built-in presets stay unchanged.

Editable bases:

  • Opaque finishes (Matte, Satin, Glossy, Ceramic, Plastic): diffuse, specular highlight amount and roughness (Plastic: phong highlight amount and size), reflection.
  • Glass (tinted), Frosted glass, Gem: as above plus the pigment filter amount and the index of refraction; Frosted glass also the bump strength and scale of its surface relief.
  • Decorative textures (Marble, Jade, Granite, Stone, Wood): the pattern scale, in the material's unit texture space (relative to each atom).

Native POV-Ray definitions (metals, M_Glass, M_Ruby_Glass) and the ASE styles are not editable.

A MaterialDefinition stores the base id, a name, the definition version, and every parameter value (also those not shown in the dialog), so a saved figure does not change if a built-in default changes later. Its id is derived from that content (custom_<base>_<digest>): two different definitions can never share an id, and a variant cannot replace a built-in or another variant.

Examples:

>>> from ycrystal.presets.custom import base_definition, schema_for
>>> satin = base_definition("satin")
>>> satin.parameter("specular"), satin.parameter("roughness")
(0.35, 0.02)
>>> shiny = satin.with_values(specular=0.7, roughness=0.005).renamed("Shiny satin")
>>> shiny.id.startswith("custom_satin_"), shiny.material().finish
(True, 'ambient 0.08 diffuse 0.75 specular 0.7 roughness 0.005')
>>> [p.key for p in schema_for("glass_frosted").visible()]
['diffuse', 'specular', 'roughness', 'reflection', 'filter', 'ior', 'bump_strength', 'bump_scale']

Gallery thumbnails¶

thumbnails ¶

Gallery thumbnails rendered by POV-Ray with fixed scenes.

Every material is shown on the same three bonded spheres (strontium, titanium, and oxygen colours) in one fixed environment (MATERIAL_ENVIRONMENT), and every environment on the same SrTiO3 unit cell with the satin material, so thumbnails can be compared with each other. The scenes are written by the ordinary scene_to_pov; the thumbnails are genuine POV-Ray images, not approximations.

The thumbnails are shipped in ycrystal/presets/thumbnails/ together with index.json, which records a digest of each scene. When a preset recipe or the scene writer changes, the digest no longer matches (the test suite checks this), and scripts/render_thumbnails.py renders the affected thumbnails again.

Examples:

>>> from ycrystal.render.thumbnails import material_scene, scene_digest
>>> text = material_scene("gold")
>>> "texture { T_Gold_3C" in text and '#include "metals.inc"' in text
True
>>> len(scene_digest(text))
64
