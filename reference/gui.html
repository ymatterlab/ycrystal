GUI adapters¶

These interfaces need Qt; the viewport also needs a display and OpenGL when created. Only Ycrystal's selected methods and signals are shown, with inherited members omitted.

MainWindow ¶

MainWindow(structure: Structure | None = None, parent: QWidget | None = None, *, project: Project | None = None, project_path: Path | None = None)

Bases: QMainWindow

The Ycrystal main window.

Creating it needs a QApplication and a display; the 3D view needs OpenGL.

Parameters:

  • structure (Structure | None, default: None ) –

    Structure to show when no project is given.

  • parent (QWidget | None, default: None ) –

    Qt parent widget.

  • project (Project | None, default: None ) –

    Project to show, including its view and settings; takes precedence over structure.

  • project_path (Path | None, default: None ) –

    File the project was loaded from; used as the default save location.

Attributes:

  • structure –

    The scientific structure shown. Navigation, selection, and hiding never change it; opening a file replaces it.

  • scene_settings –

    Current display settings; changed only through undoable commands.

  • environment –

    Background preset, transparency, and lights used for export and rendering; changed through undoable commands.

  • geometry –

    The DisplayGeometry currently drawn and exported.

  • selection (set[AtomId]) –

    Selected displayed atoms, as a set of AtomId.

  • measurements –

    MeasurementSession: the measurement mode, the atoms picked so far, and this session's distances and angles (not saved in projects).

  • undo_stack –

    QUndoStack of display-setting, material, and background changes. Camera, output size, and file actions are not undoable.

  • scene_revision –

    Counter increased by every change that affects the rendered image (view, scene, appearance, output size). Previews made for an older revision are discarded when they finish.

  • project_path (Path | None) –

    Project file of the current scene, or None if it has not been saved.

  • settings –

    QSettings with machine-specific choices (POV-Ray path, last directory).

  • last_error (tuple[str, str] | None) –

    Title and text of the last error message, for tests and scripts.

  • last_render_path (Path | None) –

    Destination of the last successful render.

  • render_finished_result (RenderResult | None) –

    RenderResult of the last finished render.

  • preview_result (tuple[RenderResult, int] | None) –

    (RenderResult, revision) of the last preview that finished, including discarded and cancelled ones.

  • preview_shown (PreviewRequest | None) –

    PreviewRequest of the preview image shown in the dock, or None.

  • preview_discarded –

    Number of preview results discarded because the scene or the preview resolution had changed.

Raises:

  • ValueError –

    If neither structure nor project is given.

Notes

The saved or default camera is applied after the window is first shown, once the layout has given the 3D view its final size. Cameras exchanged with projects, export, and rendering are output cameras: they describe the image inside the output frame.

open_file ¶

open_file(path: str | Path | None = None, fmt: str | None = None) -> bool

Open a structure file or a project, replacing the current scene.

Parameters:

  • path (str | Path | None, default: None ) –

    File to open; None shows a file dialog.

  • fmt (str | None, default: None ) –

    Format key ("poscar", "cif", "qe", or "project"); None detects it and asks if detection is ambiguous.

Returns:

  • bool –

    Whether something was loaded. False if the user cancelled (including the question about unsaved changes) or the file could not be read. Read failures show an error; cancellation does not. The current scene stays unchanged in either case.

save ¶

save() -> bool

Save to the current project file, or ask for one. Return whether it was saved.

save_as ¶

save_as(path: str | Path | None = None) -> bool

Save the project to a new file.

Parameters:

  • path (str | Path | None, default: None ) –

    Destination; None shows a file dialog. .ycrystal is appended if the name has another suffix.

Returns:

  • bool –

    Whether the project was saved; failures are shown in a message.

select ¶

select(atom_ids: set[AtomId]) -> None

Replace the selection; IDs that are not displayed are ignored.

hide_selected ¶

hide_selected() -> None

Hide the selected displayed atoms as one undoable step (Delete).

Only the selected balls disappear, from the view and from exports; other images of the same atom stay, and the structure is unchanged.

show_all_atoms ¶

show_all_atoms() -> None

Bring back every hidden atom as one undoable step (View ▸ Show All Atoms).

set_boundary_images ¶

set_boundary_images(enabled: bool) -> None

Switch boundary images on or off as one undoable step.

Hidden IDs are kept while boundary images are off and apply again when they are switched back on.

set_repetitions ¶

set_repetitions(repetitions: tuple[int, int, int]) -> bool

Change displayed cell counts as an undoable step and refit the view.

Parameters:

  • repetitions (tuple[int, int, int]) –

    Counts along a, b, c. Values are converted to integers and clamped to 1 through 20.

Returns:

  • bool –

    Whether settings changed. Expansions above 20,000 displayable atoms ask for confirmation first; cancellation leaves the scene and panel unchanged.

set_cell_mode ¶

set_cell_mode(mode: str) -> None

Set all, outline, unit, or none cell-edge mode as an undoable change.

set_bonds_enabled ¶

set_bonds_enabled(enabled: bool) -> None

Toggle displayed bonds without changing candidate rules or scientific data.

set_bond_tolerance ¶

set_bond_tolerance(value: float) -> None

Set the covalent-radius distance multiplier; consecutive edits merge in undo.

set_bond_radius ¶

set_bond_radius(value: float) -> None

Set the cylinder radius in Å; consecutive edits merge in undo.

set_bond_pair ¶

set_bond_pair(pair: Pair, enabled: bool) -> None

Override visibility for an element pair, sorting its symbols alphabetically.

view_along ¶

view_along(axis: str, reverse: bool = False) -> None

Look down a lattice (a, b, c) or Cartesian (x, y, z) axis.

The axis points toward the viewer (away with reverse); the next axis in c, b, a (or z, y, x) order that is not parallel to it points up. The same rule as ycrystal --view (axis_view).

set_material ¶

set_material(material_id: str) -> None

Set the default material of atoms and bonds (undoable).

Element and atom overrides keep precedence over the default.

set_element_material ¶

set_element_material(element: str, material_id: str | None) -> None

Set or remove (None) the material override of element (undoable).

set_atom_material ¶

set_atom_material(atom_ids: set[AtomId], material_id: str | None) -> None

Set or remove (None) the material override of displayed atoms (undoable).

Overrides refer to displayed-atom IDs, like hiding, and take precedence over element overrides and the default material.

set_selection_material ¶

set_selection_material(material_id: str | None) -> None

Set or remove the material override of the selected atoms (undoable).

clear_atom_materials ¶

clear_atom_materials() -> None

Remove every per-atom material override as one undoable step.

set_element_color ¶

set_element_color(element: str, color: tuple[float, float, float] | None) -> None

Set or remove (None) the colour override of element (undoable).

set_legend ¶

set_legend(legend: LegendSettings, text: str = 'Legend', merge_key: str = '') -> bool

Change the element legend (undoable; same merge keys merge into one step).

The legend is drawn onto the figure (view, preview, renders, exports); the camera is not changed. Returns whether the settings changed.

set_radius_scale ¶

set_radius_scale(scale: float) -> None

Set the atom size (radius ÷ covalent radius) as an undoable step.

Elements with their own radius keep it. Consecutive changes merge into one step.

set_element_radius ¶

set_element_radius(element: str, radius: float | None) -> None

Set or remove (None) the sphere radius of element in Å (undoable).

Consecutive changes of the same element merge into one step.

reset_element_appearance ¶

reset_element_appearance(element: str) -> None

Remove the colour and radius overrides of element as one undoable step.

set_background ¶

set_background(environment_id: str) -> None

Apply environment preset environment_id (undoable).

The preset sets the background, the floor, the lighting, the transparency, and a cell-edge colour that stays visible on it, as one step.

set_environment ¶

set_environment(environment: Environment, text: str, merge_key: str = '') -> None

Apply an edited environment (background, floor, or lights) as an undoable step.

Consecutive edits with the same non-empty merge_key (for example dragging a light-intensity spin box) merge into one step.

set_lighting ¶

set_lighting(lighting_id: str) -> None

Apply lighting preset lighting_id; background and floor stay (undoable).

open_lighting_setup ¶

open_lighting_setup() -> LightingSetupWindow

Show the Lighting Setup window (View ▸ Lighting Setup…), creating it once.

The window has its own overview camera and only shows the rig resolved from the output camera; its graphics never reach the main view, picking, fitting, or exports.

lighting_environment ¶

lighting_environment() -> Environment

Return the environment whose lights are shown: a drag preview or the current one.

open_material_gallery(target: str | None = None) -> PresetGallery

Show the material gallery (non-modal) and return it.

Parameters:

  • target (str | None, default: None ) –

    Preselected target: "default", "element:<symbol>", or "selection"; None keeps the previous one.

open_environment_gallery ¶

open_environment_gallery() -> PresetGallery

Show the environment gallery (non-modal) and return it.

set_rotation_mode ¶

set_rotation_mode(mode: str) -> None

Rotate freely with left drag, or only about a lattice or Cartesian axis.

Parameters:

  • mode (str) –

    "free", "a", "b", "c", "x", "y", or "z". Lattice axes fall back to free rotation for a structure without a cell.

Notes

The mode is a navigation setting: it is not saved in projects and not undoable. Rotations turn the view (camera); the structure's coordinates never change.

rotation_mode ¶

rotation_mode() -> str

Return the rotation mode: "free" or an axis name (a, b, c, x, y, z).

rotate_step ¶

rotate_step(sign: int) -> None

Turn the structure by the step angle about the rotation axis.

In free rotation the axis is the line of sight. sign +1 is counter-clockwise (right-handed about the axis), -1 clockwise. A view change, not undoable.

current_style ¶

current_style() -> Style

Return the style of the current presentation.

See ycrystal.io.style.

export_style ¶

export_style(path: str | Path | None = None) -> Path | None

Save the current style to a .ycstyle file (File ▸ Export Style…).

Parameters:

  • path (str | Path | None, default: None ) –

    Destination; None asks with a file dialog. The suffix is set to .ycstyle.

Returns:

  • Path or None –

    The written file, or None if cancelled or writing failed (an error message is shown).

import_style ¶

import_style(path: str | Path | None = None, parts: list[str] | tuple[str, ...] | None = None, element_map: dict[str, str | None] | None = None) -> bool

Apply a style file to this structure as one undoable step (File ▸ Import Style…).

Parameters:

  • path (str | Path | None, default: None ) –

    Style file; None asks with a file dialog.

  • parts (list[str] | tuple[str, ...] | None, default: None ) –

    Parts to apply (see STYLE_PARTS); None asks with a dialog that offers all of them and the element mapping.

  • element_map (dict[str, str | None] | None, default: None ) –

    {source element: target element or None} when parts is given (see resolve_element_map); None transfers by matching symbols. Ignored when the dialog asks.

Returns:

  • bool –

    Whether anything changed. Parts that could not be applied (overrides of absent elements, per-atom settings of another structure) are explained in a message. The structure's coordinates are never changed; the camera is kept, except that new repetitions refit the view.

ask_style_import ¶

ask_style_import(style: Style) -> StyleImportChoice | None

Ask which parts of style to apply and how to map its elements.

Returns None if cancelled. See StyleImportDialog.

set_output_size ¶

set_output_size(width: int, height: int, ratio: float | None = None) -> None

Set the output image size in pixels as an undoable step; the camera is kept.

The frame in the 3D view takes the new aspect ratio; the image keeps its centre and visible height in Å, so a new resolution at the same ratio keeps the composition. Values are clamped to 16–8000 pixels. Consecutive size changes merge into one undo step.

Parameters:

  • width (int) –

    New size in pixels.

  • height (int) –

    New size in pixels.

  • ratio (float | None, default: None ) –

    New target ratio of the aspect lock (from the Render panel: kept for edits, the preset for presets, inverted for Swap). None keeps the current target if the size matches it, and otherwise takes width / height.

output_size ¶

output_size() -> tuple[int, int]

Return the output image (width, height) in pixels.

aspect_locked ¶

aspect_locked() -> bool

Return whether the output aspect ratio is locked (Render panel).

aspect_ratio ¶

aspect_ratio() -> float

Return the target ratio width / height of the aspect lock.

set_aspect_locked ¶

set_aspect_locked(locked: bool) -> None

Lock or unlock the output aspect ratio (the lock button beside Width/Height).

Locking captures the ratio of the current size; neither dimension changes. The lock state is saved in projects (a change marks the project modified) but is not an undo step, since it does not change the image.

current_camera ¶

current_camera() -> Camera

Return the output camera: the view inside the output frame.

This camera, together with the output size of current_render_settings, defines the exported and rendered image and is saved in projects.

current_render_settings ¶

current_render_settings() -> RenderSettings

Return the output settings for export and final renders.

Width and height are the output size (Scene panel ▸ Render); the background is transparent when the background preset is. Antialiasing is on.

measurement_mode ¶

measurement_mode() -> str | None

Return "distance", "angle", or None (ordinary selection).

set_measurement_mode ¶

set_measurement_mode(mode: str | None) -> None

Enter a measurement mode, or leave it with None.

In a mode, clicks on atoms pick A, B (and C) instead of selecting; camera navigation is unchanged. Switching modes cancels an incomplete measurement. The ordinary selection is kept.

pick_measurement_atom ¶

pick_measurement_atom(atom_id: AtomId) -> measure.Measurement | None

Pick a displayed atom for the current measurement (as a click does).

Returns:

  • Measurement or None –

    The completed measurement, or None while more atoms are needed or when the pick was rejected (the status bar explains why).

cancel_measurement ¶

cancel_measurement() -> bool

Cancel the incomplete measurement and remove its helpers (Esc).

Also removes the guide of the measurement just completed. Returns whether there was anything to cancel; completed results stay in the table.

remove_measurements ¶

remove_measurements(rows: list[int]) -> None

Remove completed measurements by table row.

clear_measurements ¶

clear_measurements() -> None

Remove all completed measurements.

preview_settings ¶

preview_settings() -> RenderSettings

Return the settings of POV-Ray previews.

Same aspect ratio and background as the output; the size comes from the preview resolution choice (preview_size) and antialiasing is off for speed. The output settings are not affected.

preview_size ¶

preview_size() -> aspect.PreviewSize

Return the preview size for the resolution choice and the current output.

See preview_size for the rounding and the limits.

preview_resolution ¶

preview_resolution() -> tuple[str, int]

Return the preview resolution choice: (mode, requested width in px).

mode is "small", "medium", "large", or "custom".

render_image ¶

render_image(path: str | Path, options: ExportOptions, show_result: bool = True) -> bool

Start a POV-Ray render of the current view and write it as PNG, PDF, or JPEG.

POV-Ray renders options.width × options.height pixels with the current camera, geometry, and environment; a size of another shape than the output frame shows a wider or narrower area at the same scale (never stretched). The scene, the Render panel's output size, and the project are not changed.

After a synchronous version query (up to 15 seconds) and job preparation, POV-Ray runs in the background in a temporary job directory. The method returns once that process has been requested; the toolbar's Cancel stops it and the status bar shows its progress. When it finishes, the image is written to the destination by write_export (replacing an existing file only once the new one is complete), the job directory is deleted, and the image is shown or an error message explains the failure. A cancelled render leaves the destination untouched and shows no error.

  • path (str | Path) –

    Destination file; its suffix is made to match options.format.

  • options (ExportOptions) –

    Format, pixel size, resolution, and JPEG quality.

  • show_result (bool, default: True ) –

    Whether to show the finished image in a dialog.

Returns:

  • bool –

    Whether a render started. False if one is already running or POV-Ray is not found (a message explains how to set it up).

Raises:

  • OSError –

    If the temporary job directory or scene files cannot be created.

set_scene(geometry: DisplayGeometry, environment: Environment) -> None

Replace drawn atoms, bonds, cell edges, and vector arrows; keep the camera.

set_lighting ¶

set_lighting(environment: Environment) -> None

Use the lights of environment without rebuilding the scene.

The key and fill lights become VTK scene lights at the world positions of resolve_lighting for the output camera and the current geometry: positional, white, with the environment's intensities, no distance attenuation (constant attenuation 1), and no spotlight cone. RenderProcess ¶

RenderProcess(job: RenderJob, executable: str, parent: QObject | None = None)

Bases: QObject

Run POV-Ray for one job without blocking the Qt event loop.

start returns immediately; the render runs in a separate process. A running Qt event loop (QCoreApplication is sufficient; no window or display is needed) delivers the result through finished.

povray runs as a QProcess, whose output gives the progress. POV-Ray for Windows prints nothing and must start minimised, which QProcess cannot ask for in PySide6: it runs as a subprocess.Popen that a timer checks every WINDOWS_ENGINE_POLL_MS (100 ms) for its exit, with the foreground held (see hold_foreground). It reports no progress until the final 100. Only one copy of it can run at a time, so this program's renders with it take turns: one started while another runs waits (and counts as running) until that one has finished. An open POV-Ray for Windows that keeps a single instance makes the render fail at once with an explanation (see windows_engine_conflict).

Parameters:

  • job (RenderJob) –

    Prepared job; POV-Ray runs with job.directory as its working directory.

  • executable (str) –

    POV-Ray executable.

  • parent (QObject | None, default: None ) –

    Qt parent object.

Attributes:

  • job –

    The job being rendered. Its directory is not removed by this class; call job.cleanup() after finished.

  • executable –

    The POV-Ray executable.
