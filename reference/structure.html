Structure and samples¶

structure ¶

Scientific structure data, kept separate from display state.

A Structure records what a structure file describes: the lattice, Cartesian atomic positions, elements, species labels, site occupancies, per-axis movable flags, and import provenance. Display choices such as boundary images, hidden atoms, radii, and colours belong to SceneSettings and never change a structure.

The coordinate arrays of a structure are read-only copies, so viewing, navigating, hiding atoms, or rendering cannot change scientific coordinates by accident.

Structure dataclass ¶

Structure(cell: ndarray, positions: ndarray, numbers: ndarray, labels: tuple[str, ...], pbc: tuple[bool, bool, bool] = (True, True, True), metadata: dict[str, Any] = dict(), occupancy: ndarray | None = None, movable: ndarray | None = None)

A periodic or molecular structure in Cartesian ångström coordinates.

The constructor validates its arguments and copies every array into a new, read-only NumPy array, so later changes to the caller's arrays do not affect the structure and the stored arrays cannot be modified in place. To change a field, create a new structure with replace.

Attributes:

  • cell (ndarray) –

    Lattice matrix in Å, shape (3, 3). Rows are the lattice vectors a, b, and c, so the fractional row vector f is at Cartesian position f @ cell. A singular matrix (for example all zeros) means the structure has no cell; see has_cell.

  • positions (ndarray) –

    Cartesian atomic positions in Å, shape (N, 3), in input order. Positions are stored as given: atoms outside the cell are not wrapped.

  • numbers (ndarray) –

    Atomic numbers, shape (N,), each between 1 and 118. They define the element of each atom, and with it the default colour and radius.

  • labels (tuple[str, ...]) –

    One species label per atom as written in the source (for example "Fe1" or "O_2"), kept separately from the element in numbers. Readers use the element symbol when the source has no separate label.

  • pbc (tuple[bool, bool, bool]) –

    Periodicity along a, b, and c. Display code adds boundary images only along periodic axes.

  • metadata (dict[str, Any]) –

    Free-form provenance. The file readers store a "source" dictionary here (path, format, SHA-256 checksum, import time, and reader details).

  • occupancy (ndarray | None) –

    Site occupancy of each atom, shape (N,), nominally in (0, 1]. The constructor tolerates values up to 1 + 1e-6 without clipping. Passing None stores 1 for every atom, so the stored value is never None.

  • movable (ndarray | None) –

    Per-atom, per-axis "may move" flags, shape (N, 3), from VASP selective dynamics or Quantum ESPRESSO if_pos; None if the source had none. Ycrystal displays and saves these flags but never moves atoms.

Raises:

  • ValueError –

    If cell is not (3, 3), positions is not (N, 3), the number of atomic numbers, labels, occupancies, or movable rows differs from N, an atomic number is outside 1 to 118, or an occupancy is non-positive or above 1 + 1e-6.

Notes

The dataclass is frozen and compares by identity (eq=False): two structures with equal arrays are not ==. Use compare_structures for a scientific comparison.

metadata is the one mutable part: the dictionary is stored as given, not copied, and its contents can still be changed.

The constructor checks array shapes and the ranges described above, but does not reject non-finite coordinates or occupancies, or validate the length of pbc. Callers constructing structures directly must supply finite scientific data and three periodic flags.

Examples:

>>> import numpy as np
>>> from ycrystal.core.structure import Structure
>>> rocksalt = Structure(
...     cell=np.eye(3) * 4.2,
...     positions=[[0.0, 0.0, 0.0], [2.1, 2.1, 2.1]],
...     numbers=[12, 8],
...     labels=["Mg", "O1"],
... )
>>> rocksalt.symbols, rocksalt.labels
(('Mg', 'O'), ('Mg', 'O1'))
>>> rocksalt.positions.flags.writeable
False

symbols property ¶

Element symbols, one per atom, derived from numbers.

has_cell property ¶

has_cell: bool

Whether the cell is non-singular (|det(cell)| > 1e-9 Å³).

Structures without a cell are drawn without cell edges and without boundary images.

from_ase classmethod ¶

from_ase(atoms: Atoms, labels: list[str] | None = None, **metadata: Any) -> Structure

Create a structure from an ASE Atoms object.

Parameters:

  • atoms (Atoms) –

    Source structure. Its cell, positions (Å), atomic numbers, and periodic flags are copied; atoms itself is not modified.

  • labels (list[str] | None, default: None ) –

    Species labels, one per atom. None uses the chemical symbols.

  • **metadata (Any, default: {} ) –

    Keyword arguments stored as the new structure's metadata, for example source={"format": "sample", "name": "..."}.

Returns:

  • Structure –

    A new structure with occupancy 1 for every atom and no movable flags.

Notes

ASE constraints, tags, magnetic moments, and other per-atom arrays are not transferred.

replace ¶

Return a new structure with some fields replaced.

    New values for any of the fields cell, positions, numbers, labels, pbc, metadata, occupancy, and movable.

Returns:

  • Structure –

    A new structure, validated and copied by the constructor as usual. Unless a new metadata is given, it receives a shallow copy of this structure's metadata.

samples ¶

Small synthetic sample structures (no external data).

The ycrystal command shows one of these when it starts without a file (--sample perovskite, the default, or --sample triclinic).

SAMPLES module-attribute ¶

SAMPLES: dict[str, Callable[[], Structure]] = {'perovskite': perovskite_srtio3, 'triclinic': triclinic_marker}

Sample factories by the name accepted by ycrystal --sample.

perovskite_srtio3 ¶

perovskite_srtio3() -> Structure

Return cubic SrTiO3, one formula unit (5 atoms, a = 3.905 Å).

Sr is at the origin, Ti at the cell centre, and O at the three face centres (½, ½, 0), (½, 0, ½), and (0, ½, ½). With boundary images the corner Sr is drawn 8 times and every O twice, so 15 balls are shown.

Returns:

  • Structure –

    A new structure; metadata["source"] records {"format": "sample", ...}.

triclinic_marker ¶

triclinic_marker() -> Structure

Return a low-symmetry triclinic cell with distinguishable atoms.

The cell has a, b, c = 4.6, 5.3, 6.1 Å and α, β, γ = 78°, 84°, 71°, with a along x and b in the xy plane. It contains one atom each of O, Fe, S, Cl, and N at general positions, none on a cell boundary, so exactly 5 balls are shown. Because every atom differs and the arrangement has no symmetry, a mirrored or rotated rendering is visibly wrong, which makes the structure useful for checking camera export.

Returns:

  • Structure –

    A new structure; metadata["source"] records {"format": "sample", ...}.

Measurements¶

Distances and bond angles between displayed instances, used by the measurement modes of the window. Session-only: nothing here is saved in projects.

measure ¶

Interatomic distances and bond angles between displayed atoms (FR-MEASURE-01).

Measurements use the exact displayed instances the user picked. Each instance is an AtomId (source, (na, nb, nc)) at structure.positions[source] + (na, nb, nc) @ structure.cell in Å, so the result depends only on the structure: not on the camera, the projection, the drawn radii, or the display settings, and no minimum-image convention is applied. Two periodic images of the same source atom are different instances and may be measured against each other.

The functions are pure (no Qt or VTK). MeasurementSession holds the interaction state: the mode, the atoms picked so far, and the completed results of this session (they are not saved in projects).

Examples:

>>> import numpy as np
>>> from ycrystal.core.measure import bond_angle, distance
>>> b = np.zeros(3)
>>> round(distance(b, np.array([0.0, 3.0, 4.0])), 6)
5.0
>>> bond_angle(np.array([1.0, 0, 0]), b, np.array([0, 2.0, 0]))  # vertex b
90.0
>>> bond_angle(np.array([1.0, 0, 0]), b, np.array([-3.0, 0, 0]))
180.0

bond_angle ¶

bond_angle(a: ndarray, b: ndarray, c: ndarray) -> float

Return the angle ∠ABC in degrees, with b as the vertex.

Uses the arms a − b and c − b and atan2(|u × v|, u · v), which stays accurate near 0° and 180° (unlike arccos of a rounded cosine). Collinear arms give exactly 0° (same direction) or 180° (opposite directions).

Raises:

  • MeasurementError –

    If an arm is shorter than ZERO_LENGTH (the angle is undefined).

Comparison helpers¶

These support reader-equivalence checks, not GUI supercell controls.

compare ¶

Compare two structures independently of atom order and periodic wrapping.

Lattice matrices are compared directly (same orientation required). Atoms are matched one-to-one by element and by fractional position modulo lattice translations. When one description uses a conventional and the other a primitive cell, transform one of them explicitly first (for example with supercell) and record the transformation.

These helpers check reader equivalence in the test suite; the application does not use them to display anything.

Comparison dataclass ¶

Comparison(equivalent: bool, max_cell_deviation: float, max_position_deviation: float, message: str)

Result of compare_structures.

Attributes:

  • equivalent (bool) –

    Whether the structures agree within the tolerance.

  • max_cell_deviation (float) –

    Largest absolute difference between corresponding lattice-matrix elements, in Å; infinite if the atom counts or elements already differ.

  • max_position_deviation (float) –

    Largest distance in Å between matched atoms, or the distance of the first atom without a partner; infinite if positions were not compared.

  • message (str) –

    "equivalent", or a short reason for the difference.

compare_structures ¶

compare_structures(a: Structure, b: Structure, tolerance: float = 0.0001) -> Comparison

Check whether two structures describe the same crystal in the same cell.

The checks run in order and stop at the first difference: atom count, multiset of elements, lattice matrices element by element, and finally atom positions. Each atom of a is matched to the nearest unused atom of b with the same element, using fractional coordinates in the cell of a with whole lattice translations removed; the remaining offset is measured in Å.

Parameters:

  • a (Structure) –

    First structure.

  • b (Structure) –

    Second structure.

  • tolerance (float, default: 0.0001 ) –

    Largest accepted deviation in Å, for lattice-matrix elements and for atom positions.

Returns:

  • Comparison –

    The verdict with the largest deviations found.

Raises:

  • LinAlgError –

    If the first cell is singular and the checks reach position matching.

Notes

Matching is greedy, which is reliable for atoms that are much farther apart than tolerance. Lattice translations are removed along all three axes, whatever the periodic flags. Labels, occupancies, movable flags, and metadata are not compared. Fractional differences are wrapped component by component; this is not a general minimum-image search for highly skewed cells.

supercell ¶

supercell(structure: Structure, matrix: ndarray) -> Structure

Return the same crystal described in the cell matrix @ structure.cell.

Parameters:

  • structure (Structure) –

    Structure to transform; it is not modified.

  • matrix (ndarray) –

    Non-singular integer (3, 3) transformation. Row i gives new lattice vector i in units of the old lattice vectors.

Returns:

  • Structure –

    A new structure built with ASE's make_supercell (atoms wrapped into the new cell). Labels are reset to element symbols; occupancies, movable flags, and metadata are not carried over.

Notes

This is a comparison helper. It is unrelated to displaying supercell repetitions, which are handled separately by SceneSettings and build_geometry.
